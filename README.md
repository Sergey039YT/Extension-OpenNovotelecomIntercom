# Расширение - OpenNovotelecomIntercom
## О проекте
Это расширение добавляет кнопку открытия двери на камеру домофона на сайте просмотра камеры домофона (https://video.2090000.ru и для других городов).
Для появления кнопки необходимо авторизоваться через интерфейс расширения
Код писался без использования ИИ. Для удобства (в первую очередь своего) были оставлены комментарии в коде.

## Установка

### 1) Скачайте данный репозиторий
Можно использовать GIT или просто скачать как архив
### 2) Распакуйте архив (если вы скачали репозиторий как архив)
### 3) Включите режим разработчика в браузере
(см. инструкцию к своему браузеру. На Opera этот переключатель находится в списке расширений)
### 4) Нажмите "Загрузить распакованное расширение" и выберите папку с расширением
`После установки, расширение появится в списке расширений`
